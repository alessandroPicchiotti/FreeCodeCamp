flex-direction,     justify-content,     align-items,    flex-wrap.

flex-grow, flex-shrink e flex-basis. --> sintassi contratta: flex: 1 1 100px; --> allarga in volte | stringi in volte | alrghezz in px |

modello flex: 
    L’asse principale: flex-direction -> row o column di default parte da sinstra-destra '''flex-direction: row; /* Default */'''', se vuoi destra-sisnitra row-reverse
                        main {
                            display: flex;
                            flex-direction: column; 
                          }

    L’asse trasversale: è sempre perpendicolare all'asse principale

FLEX-WRAP: AVVOLGE, nowrap è il valore predefinito: NOWRAP: se superano ridimensione, con WRAP avvolge lasciando invariate le larghezze del div figli
La proprietà flex-wrap determina come si comportano i tuoi elementi flex quando il contenitore flex è troppo piccolo. Impostarla su wrap permette agli elementi di andare a capo sulla riga o colonna successiva. nowrap (predefinito) impedisce agli elementi di andare a capo e li riduce se necessario.

proprietà "flex-flow" è una proprietà abbreviata per "flex-direction" e "flex-wrap"

justify-content: center;
justify-content: flex-end;
justify-content: flex-start;
justify-content: flex-start;
justify-content: space-around;
justify-content: space-evenly;


***********ASSE TRAVERSALE***********************

align-items: center;
align-items: flex-start;
align-items: flex-end;

Per allungare gli elementi flex lungo l'asse trasversale, puoi usare:
align-items: stretch

.container {
  display: flex;
  align-items: flex-start; 
  border: 2px solid #444;
  height: 200px; 
}

.box {

  border: 1px solid #888;
  background-color: lightblue;
  margin: 4px;
}

.special {
