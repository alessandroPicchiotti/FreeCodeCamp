}

  border-color: blue;
}

********** ESEMPIO****Stilizzare un elemento genitore basandosi sugli stati dei suoi figli *** :has()********
<article>
  <h2>Subheading</h2>
  <p>Lorem ipsum dolor sit amet.</p>
</article>

<article>
  <h3>A point</h3>
  <p>Lorem ipsum dolor sit amet.</p>
  <p>Lorem ipsum dolor sit amet.</p>
</article>

article:has(h2) {
  border: 2px solid hotpink;
}

******ESEMPIO***:not()*********i vuoi applicare stili a un gruppo di elementi, escludendo una o più eccezioni specifiche********
<button class="primary">Primary Button</button>
<button class="secondary">Secondary Button</button>
<button class="danger">Another Secondary Button</button>

button:not(.primary) {
  background-color: grey;
}
